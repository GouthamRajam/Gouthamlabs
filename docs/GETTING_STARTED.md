# Getting started
1. Read docs/MASTER_SPEC.md fully.
2. Copy .env.example to .env and fill in your model API key.
3. Open SESSION_PROMPTS.md. Paste Session 1 into your coding agent (e.g. Claude Code).
4. Build milestones in order. Each ends with a report in docs/milestones/.
5. To view the concept UI now: open demo/live_office.html in a browser (it is a
   scripted simulation, not real output).

Nothing is implemented yet — this is a scaffold plus the full specification.
