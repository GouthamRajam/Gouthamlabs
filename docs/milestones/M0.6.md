## What was built (plain English)

**Zone 2B: build the tests (manager Nadia).** The **independence rule** is enforced by file permissions: no 2B agent is ever given an RTL file. They see only the design's port list, which Yosys extracts.
- **Vera** writes the test plan. For every requirement it lists the tests that prove it, plus "coverage bins": conditions on the pins that must be seen at least once.
- **Mira** writes the reference model from the spec, twice, in two separate model calls that never see each other.
  - The two models run on the same 2000 random inputs and their outputs are compared. This is the N-version check.
  - Any difference goes to Vera, who decides from the spec, or stops the run for a human if the spec does not decide it.
- **Proto** writes a protocol checker when a design uses a standard protocol (uart). The checker comes with its own tests, including tests that must make it fire.
- **Theo** writes the cocotb testbench.
  - A large test plan does not fit in one model answer. In that case Theo writes a shared environment first, then the tests in batches.
- **Euclid** writes formal properties on the pins only.
- **Sentinel** reviews all of the above. The reviewed set becomes the "baseline" that later changes are compared against.

**Zone 2C: close verification (manager Rhea).**
- **Rex** runs the regression: Verilator with seeds 1–3, plus an Icarus cross-check. A failure is re-run on the same seed to detect flaky tests.
- **Coverage is measured by the tools, never reported by the testbench:**
  - Line and toggle coverage come from Verilator.
  - Coverage bins are evaluated on the simulator's own waveform.
- **Formal (Euclid's properties)** runs in SymbiYosys. A property counts only if all three hold:
  - it is proven;
  - its trigger is reachable (the vacuity check);
  - it fails when the design is replaced by a stub with random outputs. Otherwise it checks nothing about the design.
- **Dex** classifies every failure:
  - **DESIGN:** the RTL owner fixes it, then lint re-runs.
  - **TEST:** Theo or Euclid fixes it.
  - **SPEC:** the run stops for a human.
- **Cora** closes coverage holes with new tests. It may never delete a coverage bin.
- **Myra** injects 20 realistic bugs into copies of the final RTL and checks that the tests catch them.
  - Bug types: wrong operator, off-by-one, stuck bit, missing reset, swapped condition, dropped handshake.
  - Any injected bug that Yosys proves is identical in behavior to the original is set aside, because no test could ever catch it.
- **Anti-cheating guard:** every change to tests, test plan or properties is compared with the previous version. The guard flags deleted tests, fewer assertions, fewer iterations, new skip markers, always-true asserts, swallowed failures, removed bins and extra assumptions. A flagged change needs Sentinel's approval, and a rejected change is undone.

Model-written test code only ever runs inside the network-less EDA container.

## Real bugs the verification found
- **counter8, sync_fifo:** **none.** Every test passed against the RTL on the first regression, and 20/20 injected bugs were caught, so the tests can see bugs of these kinds. There were simply none to find.
- **uart: 1 real RTL bug, confirmed by Dex; not fixed yet.** After the cap was raised, Dex triaged the failures three times and classified the bug as DESIGN each time. It covers 20 failing runs in REQ-001, REQ-006, REQ-011 and REQ-013.
  - `uart_tx` accepts a byte and then holds `tx` high until the next free-running tick16.
  - So the start bit begins 1 to `baud_div` cycles late, and `tx_ready` stays low too long.
  - **Fix attempt 1** by the RTL owner (Ada-C) kept the ports but failed Verilator lint (`m0.6-evidence/uart_tx_fix_attempt1_lint_failed.v`).
  - **Fix attempt 2's answer** arrived. The task then exceeded its per-task token budget and paused before that fix was linted or tested.
  - `uart_tx.v` was restored to the reviewed M0.5 version, with an event recording why, so no unchecked RTL is left in place.
- **uart:** Dex also classified 12 failing runs as a **test** problem:
  - The reference model re-aligns its receive sampling to the incoming edge.
  - The RTL samples on the free-running tick that the architecture specifies.
  - So cycle-exact comparisons fail even when the receiver works (`uart_dex_bug_1_2.json`).
- **uart: the anti-cheating guard caught real model behavior.**
  - Sentinel filed 2 blocking findings: the tests at the slowest baud setting check too little.
  - Asked to fix them, Theo deleted two tests (`test_bit_period_random_divisors`, `test_baud_115200_error`) and cut a loop's iterations.
  - The guard flagged all three changes, Sentinel rejected them, and the original tests were restored. The 2 findings remain open.

## Problems found in my own work during the real runs (all fixed, with tests)
1. **Mutation harness, found before any real run:** the testbench was not mounted in the container, so every injected bug looked "caught" (a fake 100%).
   - Now the unmodified RTL must pass the same path first, and an infrastructure error never counts as a catch.
2. **Formal parser:** it read SymbiYosys's end summary, which lists only a few results and then "and N further traces".
   - Reachable properties looked vacuous and real ones looked always-true, so Euclid rewrote good properties. On counter8 one rewrite caused a 50-minute formal run.
   - The reviewed properties were restored, with an event recording why.
3. **Orchestrator freeze (dates from M0.3):** a database lock made the watchdog wait for a whole step to finish, which froze scheduling for 50+ minutes.
   - The watchdog now uses a lock that does not wait (Postgres `FOR NO KEY UPDATE`). A regression test reproduces the old 30-second block.
   - Long steps now send heartbeats.
4. **Formal time limit:** each SymbiYosys run now gets 10 minutes. A timeout is sent back to Euclid as a property-quality problem.
5. **Vacuity check:** a failing assertion could hide reachable triggers. Assertions are now removed for the reachability run.
6. **Mutation screen on sync_fifo:** the equivalence check timed out on the FIFO memory and crashed. Unscreened bugs were then recorded as "does not compile", leaving 1.
   - Timeouts now mean "unknown" (the bug is kept and counted), and a missing result is an error.
7. **Theo's answer size:** uart's 31-test testbench did not fit in one answer. Theo now writes an environment plus batches (the CEO's choice).
8. **Undone guard changes:**
   - Reverting Theo's rejected change did not restore the recorded file hashes. Nadia's spot check caught it.
   - The "Sentinel test review" check was recorded as passed although its blocking findings were never fixed. Now it fails in that case.
9. **RTL fix loop (uart):** the RTL owner's first fix changed the module's ports and broke elaboration.
   - A fix now has up to 3 attempts, and lint errors are fed back after each one.
   - Ports must match `arch.yaml`.
   - If every attempt fails, the RTL is reverted and the task is blocked.

The first counter8 run was stopped by me ($0.69) to fix routing gaps. It remains in the database, marked "stopped by the operator", and its cost counts toward counter8.

## Honest limits
- Green tests and caught injected bugs mean the testbench *can see* bugs of those kinds. They do not prove the design is correct in every case. First silicon is the final proof.
- The N-version check compares two models from the **same model family**. The spec prefers different families; only one is configured.
- Rex and Myra run as fixed rules in Phase 0 (scheduling, seeds, mutation). Their prompts are stored for M0.9.
- Formal properties are on pins only, by design (independence rule). Internal properties would need a reviewed exception.
