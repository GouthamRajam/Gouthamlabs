## Step 3 — DFT (Scan Insertion + ATPG)

### Scan Insertion

All 1,527 `dfxtp_1` DFFs replaced with `sdfxtp_1` scan cells via Yosys techmap.
SCD/SCE tied to constant 0 (scan chains not yet stitched — physical implementation detail).

### ATPG Fault Simulation

| Metric              | Value (2048 pat) | Value (8192 pat) |
|---------------------|-------------------|-------------------|
| Total stuck-at faults | 16,820          | 16,820            |
| Detected faults     | 11,926            | 13,977            |
| Undetected faults   | 4,894             | 2,843             |
| **Fault coverage**  | **70.90%**        | **83.10%**        |
| Runtime             | 2.1s              | 5.3s              |

Method: compiled C fault simulator generated from Yosys JSON netlist.
Bit-parallel evaluation (64 patterns per uint64_t word), topological-order
gate evaluation, per-gate fault injection with `__builtin_expect` fast path,
fault dropping. Random test patterns (LFSR seeded).

83.10% with random patterns is expected for a complex processor without
directed ATPG. The remaining ~17% requires structural test generation
(PODEM/D-algorithm), which is a Phase 1+ activity.
