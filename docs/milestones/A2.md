Synthesis via Yosys `synth -top s2s_rv32i_core` -> `dfflibmap` -> `abc` with sky130 liberty.
Clean mapping, no latches, no logic loops.

s2s_rv32i is ~12% larger than PicoRV32, which is expected:
- 5-module hierarchy vs PicoRV32's monolithic design
- Dedicated CSR unit (251 lines) vs PicoRV32's inline CSR handling
- Separate decoder, ALU, and register file modules
- Multi-cycle FSM (8 states) vs PicoRV32's 2-cycle design

## Step 3 — Equivalence Verification

### 3a. Formal (BMC) — FAILED (known limitation)

Same limitation as PicoRV32 (documented in P1.3): BMC/k-induction fails because
Yosys re-encodes the register file during synthesis (32x32-bit 2D array -> 1,794
individual flip-flops with different naming). The solver finds symbolic initial states
where the encoded representations diverge, producing counterexamples at steps 3-10.

Methods attempted and failed:
1. `equiv_opt` — cell re-encoding prevents output matching
2. `equiv_make` / `equiv_induct` — cannot match register file signals
3. SymbiYosys BMC (hierarchical) — gate module resolves to RTL submodules
4. SymbiYosys BMC (flat) — counterexample at step 7 from register encoding

### 3b. Gate-Level Compliance Simulation — **39/39 PASS, all signatures match RTL**

Full riscv-arch-test RV32I suite (39 tests) run on the flat synthesized gate netlist
(`s2s_rv32i_flat_gate_renamed.v` + sky130 behavioral cell models) via Icarus Verilog.

**Every gate-level test signature matches the RTL simulation signature exactly.**

This is stronger equivalence evidence than PicoRV32 Phase 1 had (which used only a
9-instruction smoke test). The full 39-test suite exercises every RV32I instruction
through the gate netlist, and the cycle-exact signature match proves that synthesis
preserved the RTL's functional behavior for all tested instruction patterns.
