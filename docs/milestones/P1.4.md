## Antenna Strategy

**Architecturally correct pre-DRT diode insertion** — per CEO directive and
the P1.0A spike conclusion (post-detailed-route antenna repair does NOT converge
on the pinned OpenROAD edf00dff).

Flow order:
1. GlobalRouting — estimates wire lengths
2. CheckAntennas — identifies GRT-model antenna violations
3. HeuristicDiodeInsertion (Odb) — inserts sky130_fd_sc_hd__diode_2 at gates of long nets (>90 µm)
4. RepairAntennas — iterates up to GRT_ANTENNA_ITERS times with GRT_ANTENNA_MARGIN% over-fix
5. DetailedRouting (TritonRoute) — physical routing with iterative DRC convergence
6. CheckAntennas (post-DRT) — final antenna check on physical routing

This is the correct fix path identified in P1.0A: insert enough diodes BEFORE
TritonRoute runs, so the detailed router inherits an antenna-clean topology.

The heuristic diode insertion is conservative — it targets ALL nets exceeding
a Manhattan-length threshold (~90 µm), not just the ~50 nets that actually
violate antenna rules. This produces a clean result but at significant area
cost. **Flagged as a Phase 1.5 efficiency target:** reduce diode count via
tuned margin thresholds and targeted insertion (insert only on nets the GRT
model predicts will violate, not all long nets). The current result proves
the strategy works; optimizing the diode budget is future work.

## Configuration

Winning config: `docs/milestones/p1.4-evidence/config.json`
SDC constraints: `docs/milestones/p1.4-evidence/constraints.sdc`

Key tuning decisions:
- **FP_CORE_UTIL 35** (pnr_ranges.yaml allows 30–65): lower utilization gives the
  router more routing resources, avoiding the met3 layer-promotion that caused Run 2's
  last violation.
- **GRT_ANTENNA_ITERS 15, GRT_ANTENNA_MARGIN 30%** (max allowed by pnr_ranges.yaml):
  maximum repair effort on the global-route estimate.
- **RUN_HEURISTIC_DIODE_INSERTION true**: the Manhattan-length heuristic inserts diodes
  at gates of long nets before GRT repair begins, providing a baseline of antenna
  protection that GRT repair then refines.
- **CLOCK_PERIOD 50.0 ns** (20 MHz): matches P1.3 synthesis target.
- **set_false_path on rst**: justified — asynchronous reset with no timing relationship
  to clk.

All parameters within pnr_ranges.yaml bounds. No rules weakened, no waivers applied.
