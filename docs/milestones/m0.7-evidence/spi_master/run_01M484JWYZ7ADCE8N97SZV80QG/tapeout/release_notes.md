# spi_master release notes

## What this package is

Tape-out package for `spi_master` (SPI master, modes 0-3, 8/16-bit MSB-first, programmable SCK divider, auto or manual chip select, transfer-complete interrupt), spec version 2, PDK sky130A, library sky130_fd_sc_hd, 50 MHz clock. This is a Phase 0 package built with open-source tools and the open SKY130 PDK only. No silicon was manufactured or tested; all results are pre-silicon. The PDK/library choice is a DEFAULT flagged in the spec as needing G1 review.

## Scope labels

- **DFT: deferred. Not measured, 0 fault coverage.** Plan only (dft_plan.md); earns no credit. Achievable with open tools (OpenROAD DFT + Fault) in Phase 1.
- **IR/EM: static IR measured and passed; EM not analysed** (Phase 1).
- Signal integrity/crosstalk, reliability (aging, ESD, latch-up), foundry-certified signoff: not run; excluded from Baseline A.
- Power: estimated at 20% input activity; the spec has no power budget.

## Known limits

- DRC/LVS use open-source Magic, KLayout and Netgen decks. A foundry's certified decks (e.g. Calibre) were not run and may differ.
- Timing is OpenSTA at the PDK typical/slow/fast corners: no OCV/AOCV, no SI-aware timing.
- No physical silicon was made or tested.
- Scope limits from the spec: max SCK 6.25 MHz (N>=4), single chip select, parallel control port, no register bus, no FIFOs.
- The spec's G1-review DEFAULTs (PDK/library, clk_div<4 clamping, CS timing, IO delays, area limit) are placeholders for human decision.

## DFM scorecard

0 high, 2 medium, 5 low open items.

- DFM-003 (medium): met1, 103 line ends at near-minimum spacing; the only item with a direct defect mechanism (line-end pull-back can open or bridge).
- DFM-001 (medium): li, 20 windows within 10% of the 0.6 max density (worst window 0.583).
- DFM-004 to DFM-007 and DFM-002 (low): near-limit geometry on met1 (53.6%), li (100.0%), met2 (81.2%), met3 (59.7%), met4 (24.6%) of edge length within 5% of min width/spacing. For li, the report notes this is inherent to minimum-width local routing and only 582 edges are near min space.
