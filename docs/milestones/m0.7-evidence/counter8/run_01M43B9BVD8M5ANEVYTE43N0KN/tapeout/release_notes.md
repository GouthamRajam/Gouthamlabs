# counter8 Release Notes (Phase 0 tape-out package)

## What this package is

counter8 is an 8-bit up/down counter with synchronous active-low reset, enable and load (spec/spec.yaml, version 1). Target: sky130A, sky130_fd_sc_hd, 100 MHz clock (10 ns). The package holds the final GDSII, netlist, constraints, signoff reports, evidence packets, versions.lock, reproduce.sh and these notes. It is a pre-silicon result from open-source tools (open SKY130 PDK, Magic, KLayout, Netgen, OpenSTA, OpenROAD). No silicon was manufactured or tested.

## Known limits

- Open-source decks only (Magic, KLayout, Netgen). Foundry-certified decks (e.g. Calibre) were not run and may differ.
- Timing is OpenSTA at the PDK corners (9 corners); no OCV/AOCV, no SI-aware timing.
- The PDK release is not pinned and several spec choices are marked DEFAULT - needs G1 review (clock target, load/up_down semantics, wrap-around, control priority). Spec open questions: whether load while enable=0 is acceptable (default yes); whether a carry/overflow flag is needed (not included); which sky130A release and STA corners apply.
- All results are pre-silicon, from simulation and layout tools.
- Readiness figures were regenerated by backend/scripts/regen_readiness.py (decision in docs/DECISIONS.md, 2026-10-06) without re-running the tools (tools_rerun: false).
