## 2. What this package is

The Phase 0 tape-out package for the `uart` design: a UART transmitter and receiver with 8N1 and configurable parity (none/even/odd), a 16-bit baud divisor, 16x oversampling receive, and framing and parity error flags (spec/spec.yaml, version 1). Target: SKY130A, library sky130_fd_sc_hd, single clock clk at 50 MHz, synchronous active-low reset rst_n. Phase 0 uses open-source tools and the open SKY130 PDK only. No physical silicon was manufactured or tested; all results are pre-silicon, from simulation and layout tools.

## 8. Known limits

- PDK is open SKY130 with library sky130_fd_sc_hd, not a commercial foundry PDK. The 50 MHz target and the PDK/library choice are marked DEFAULT in the spec and need G1 review.
- DRC/LVS used open-source Magic, KLayout and Netgen decks. A foundry's certified decks (e.g. Calibre) were not run and may differ.
- Timing: OpenSTA at the PDK's corners, with no OCV/AOCV and no SI-aware timing.
- Power/IR: 20% switching activity unless simulation activity was used; IR/EM limited to what the open flow supports.
- overrun_err is tied to 0 in this version (REQ-022); the spec notes a reviewer may remove it at G1.
- The regeneration of tapeout_readiness.json (backend/scripts/regen_readiness.py, docs/DECISIONS.md 2026-10-06) did not re-run any tools (`tools_rerun: false`).
