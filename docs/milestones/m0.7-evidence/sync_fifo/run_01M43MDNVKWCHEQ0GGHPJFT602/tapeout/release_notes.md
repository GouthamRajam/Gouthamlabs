# Release Notes: sync_fifo (Phase 0 tape-out package)

## What this package is

Tape-out package for `sync_fifo`: a single-clock synchronous FIFO, 16 entries x 32 bits, with full, empty and almost-full flags and sticky overflow/underflow protection (spec version 1). Target is SKY130A, library `sky130_fd_sc_hd`, 100 MHz (10 ns) clock. The package covers the GDSII layout, netlist, constraints, signoff reports, evidence packets, `versions.lock`, `reproduce.sh` and hashes. All results are pre-silicon, from open-source simulation and layout tools. No silicon was manufactured or tested.

The pass criterion is the hard-check verdict above. The percentages below are derived figures (`derived: true`), copied from `tapeout_readiness.json`. None is estimated here.

| Baseline | Meaning | Earned / weights | Reported percentage |
|----------|---------|------------------|---------------------|

| B | Commercial production tape-out on a real foundry PDK | 68.0 / 106.0 | 64.1% |

Arithmetic (earned points per row, from the report):

- Baseline A earned: 12 (functional sim) + 8 (coverage) + 10 (formal/equiv) + 14 (DRC) + 14 (LVS) + 4 (antenna) + 4 (density) + 12 (STA) + 4 (power) + 2 (static IR/EM) + 0 (DFT) + 6 (GDS integrity/repro) = 90. Signal integrity, reliability and foundry signoff (3 + 3 + 3 = 9 weight) are excluded from A, so A weights are 106 - 9 = 97.
- Baseline B earned: 12 + 8 + 10 + 7 (DRC) + 7 (LVS) + 4 + 4 + 6 (STA) + 2 (power) + 2 (static IR/EM) + 0 (DFT) + 0 + 0 + 0 (SI, reliability, foundry signoff) + 6 = 68. B weights are all rows, total 106.
- Partial-credit values used: dft = 0.0, ir_em = 0.5, other = 0.5. Under Baseline B, DRC, LVS, STA and power earn half their weight (the 0.5 "other" value) because open-tool decks are not foundry-certified. Static IR/EM earns 2 of 4 under both baselines. DFT earns 0 under both.
- The percentages are reported in `tapeout_readiness.json` as 92.7 and 64.1; the report does not state a rounding convention (see open items).

## Known limits

- PDK is SkyWater SKY130 (open), library sky130_fd_sc_hd. It is not a commercial foundry PDK.
- DRC/LVS use open-source Magic, KLayout and Netgen decks. Foundry-certified decks (e.g. Calibre) were not run and may differ.
- Timing is OpenSTA at the PDK typical/slow/fast corners. There is no OCV/AOCV and no SI-aware timing.
- Power/IR estimated at 20% switching activity unless simulation activity was used.
- Spec items flagged DEFAULT or needing G1 review (100 MHz target, PDK/library choice, almost-full threshold of 12, simultaneous push/pop priority at full and at empty) are carried as written in `spec/spec.yaml`. Checklist item 1 records the G1 gate as done.
